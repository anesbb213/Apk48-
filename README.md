# موسوعة الجزائر والعالم 🇩🇿

تطبيق Android أصلي متكامل مبني باستخدام **Jetpack Compose** و **Kotlin**، مع دعم كامل للغة العربية واتجاه RTL وتصميم فاخر يعتمد على الألوان الزرقاء الداكنة والذهبية المستوحاة من الهوية البصرية الجزائرية الأصيلة.

## مميزات التطبيق:
1. **قسم الجزائر**: الولايات الـ 58، العواصم، المساحة، السكان، المعالم التاريخية والتراث العريق.
2. **رؤساء الجزائر**: قائمة توثيقية لرؤساء الجزائر منذ الاستقلال مع نبذات وأحداث تاريخية.
3. **قسم العالم**: دول العالم، العواصم، القارات، العملات، اللغات والمعلومات العامة.
4. **أدوات ذكية**: حساب المسافات، المفضلة، البحث الشامل، والعمل دون انترنت تماماً.
5. **التصميم**: واجهة فاخرة بألوان ملكية (أزرق داكن وذهبي) مع دعم RTL كامل.

## البناء التلقائي عبر GitHub Actions:
يحتوي المشروع على ملف إعداد جاهز في `.github/workflows/build-apk.yml` لبناء ملف APK تلقائياً عند كل رفع (Push) أو إنشاء إصدار (Tag).
